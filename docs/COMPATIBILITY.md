## Isolation during development

- CLI: `claude --plugin-dir <repo>` loads Redact Restore into that session only. Hot reload applies only to sessions that loaded the folder.
- Desktop: the local-scope install writes `enabledPlugins` into `<test folder>/.claude/settings.local.json`, so only sessions opened on that folder load it. The `redact-restore` marketplace entry lives in user settings; remove it with `claude plugin marketplace remove redact-restore`.
- Options for a `--plugin-dir` plugin are read from user settings, `--settings`, or managed settings under `pluginConfigs` (project settings are not read). Use a scratch `--settings` file for synthetic values.
